4. 实现原理说明

动效1 虚线流动 — SVG stroke-dasharray + @keyframes stroke-dashoffset 偏移
动效2 脉冲发光 — box-shadow 在两个强度之间循环 (ease-in-out infinite)
动效3 移动小点 — translateX + opacity 组合，通过 animation-delay 错开多个点
动效4 淡入上浮 — translateY(20px→0) + opacity(0→1)，delay 递增实现依次出现
动效5 悬停交互 — Tailwind 的 group-hover + transition-all，纯 CSS 无 JS
动效6 光线扫过 — linear-gradient 背景 + background-position 动画

本页面所有动效均为纯 CSS 实现，无任何 JavaScript 动画库。

技术栈：Tailwind CSS (CDN) + 自定义 @keyframes + SVG
