5 分钟上手

从克隆到查询，只需几步

terminal 
# 克隆项目
$ git clone https://github.com/michaelwang123/mountainKing.git
$ cd mountainKing

# 安装依赖并运行
$ go mod download
$ go run cmd/server/main.go

# 开发模式（启用 Playground）
$ GRAPHQL_SERVER_MODE=development go run cmd/server/main.go

# 访问 GraphQL Playground
$ open http://localhost:8080/playground
